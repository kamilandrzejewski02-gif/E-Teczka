# E-Teczka
System mobilnej ewidencji czasu pracy

Opis projektu
Aplikacja mobilna umożliwiająca rejestrowanie czasu pracy pracowników. System pozwala na zapisywanie godzin rozpoczęcia i zakończenia pracy oraz przeglądanie historii obecności.

Funkcjonalności
- Logowanie użytkowników.
- Rejestrowanie rozpoczęcia i zakończenia pracy.
- Przeglądanie historii czasu pracy.
- Podsumowanie przepracowanych godzin.
- Zarządzanie pracownikami przez administratora.

Technologie
- Flutter / Dart
- Python / Jango
- PostgreSQL
- Rest API
- Git
